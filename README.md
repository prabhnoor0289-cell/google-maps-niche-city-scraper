# USA Google Maps Niche + City Scraper

Scrapes Google Maps business listings for a given niche and US city.

## Input
- `niche`: business type, e.g. "plumber"
- `city`: e.g. "Austin, TX"
- `maxResults`: how many listings to pull (default 50)

## Output
Each item: name, address, phone, website, rating, reviewsCount, category
